# VOXELSPACE · 体素星际

一个运行在浏览器里的体素沙盒太空生存游戏：从地球坠毁求生开始，采集、建造、修复飞船，进入太空，探索太阳系、卫星、小行星带与空间站，最终驾驶大型殖民船跃迁到其他恒星系。

**Minecraft 式体素世界 × No Man's Sky 式探索循环 · Three.js · MIT · 纯浏览器运行**

[▶ 在线试玩](https://lin14159265.github.io/VoxelSpace/) · [⬇ 下载最新版](https://github.com/lin14159265/VoxelSpace/releases/latest) · [🧭 Universe V2](./UNIVERSE-V2.md) · [🧪 验收报告](./FINAL-REPORT.md)

> 当前公开版本：**v0.1.0**。游戏素材、纹理与音效均由程序生成；公共仓库刻意不包含本地实验模型、测试截图、备份和日志等中间产物。

## 你会经历什么

一局从“坠毁”到“首次跨星系”的主流程约由 17 个阶段组成：

**坠毁求生 → 采集资源 → 制作工具 → 建造基地 → 修复飞船 → 起飞 → 进入太空 → 探索行星与卫星 → 小行星采矿 → 空间站交易与任务 → 舰船升级 → 购买大型殖民船 → 跃迁其他恒星系。**

主线完成后不会结束存档，可以继续自由探索、建造、战斗和跑任务。

## 核心特点

- **体素生存与建造**：无限区块地形、洞穴、矿脉、湖泊、植被、基地终端、储物箱和多种建材。
- **从地表到太空**：修复飞船后直接进入飞行阶段，并在地表、行星系统、恒星系统之间导航。
- **Universe V2**：天体使用统一注册表和真实量级参数；恒星系统内采用米制坐标与浮动原点渲染。
- **行星差异化**：不同重力、昼夜长度、大气密度、天气、环境危险、地形与资源分布。
- **可登陆卫星与小行星带**：月球、木星四大伽利略卫星、土卫六、海卫一、天王星主要卫星等均有独立体验；主小行星带可采矿并存在微陨石风险。
- **完整循环**：采集、合成、建造、生存、战斗、任务、交易、舰船升级和跨星系探索形成连续成长链。
- **单文件离线版**：正式构建产物为 `VOXELSPACE.html`，不安装 Node.js 也能直接游玩。

## 立即游玩

### 方式 A：在线试玩

打开：**https://lin14159265.github.io/VoxelSpace/**

GitHub Pages 会直接部署仓库中的单文件正式版。

### 方式 B：下载离线版

进入 [Releases](https://github.com/lin14159265/VoxelSpace/releases/latest)，下载 `VOXELSPACE-standalone.zip`，解压后使用 **Chrome / Edge** 双击 `VOXELSPACE.html`。

- 不需要 Node.js。
- 不需要 `npm install`。
- 不需要本地服务器。
- 存档和设置保存在浏览器本地，可在游戏内导出 / 导入存档文本。

### 方式 C：从源码运行

需要 Node.js 18+：

```bash
npm install
npm start
```

然后访问 `http://localhost:8080`。Windows 也可以直接双击 `start.bat`。

## 技术结构

项目刻意保持轻量，没有引入完整游戏引擎或前端框架。

```text
VOXELSPACE.html    单文件自包含正式版
src/
  core/            主循环、输入、UI、音频、设置
  world/           区块生成、网格、噪声、方块与纹理
  entities/        玩家、飞船、生物、战斗、天气、空间站等
  space/           Universe V2、天体数据、太空与跃迁
  render/          天空与渲染辅助
  systems/         背包、合成、任务、存档、经济、NPC、里程碑
server.js          零依赖静态服务器
start.bat          Windows 一键启动
tests/             逻辑 / 单元测试
tools/             浏览器回归、长测、性能与单文件构建工具
```

主要运行依赖只有 `three`；开发测试使用 `playwright-core`。

## 自动发布

仓库包含三条基础自动化：

- **CI**：PR / `main` 更新时执行核心 Node 测试。
- **GitHub Pages**：`main` 更新后部署 `VOXELSPACE.html` 为在线试玩版。
- **Release**：读取 `package.json` 版本号；若对应 `vX.Y.Z` Release 尚不存在，则自动打包并发布 `VOXELSPACE-standalone.zip`。

因此新版本发布时，只需要先更新 `package.json` 中的版本号，并重新生成 `VOXELSPACE.html`。

## 已知边界

当前仍是个人独立开发的早期公开版本，主要限制包括：

- NPC 支线内容较少。
- 暂无手柄与触屏操作方案。
- 存档基于浏览器 `localStorage`，重要存档建议使用导出功能备份。
- 大量系统已经可玩，但“内容宽度”明显高于美术资产与叙事深度，后续会优先依据真实试玩反馈继续打磨核心体验。

## 反馈与贡献

如果你实际试玩过，最有价值的反馈不是“再加一个功能”，而是：

- 哪一步让你不知道接下来做什么；
- 哪个操作明显别扭；
- 哪段流程无聊、重复或过长；
- 哪个 Bug 会让你无法继续；
- 哪个瞬间真正让你觉得“这个游戏有点意思”。

可以直接在 Issues 中选择 **Bug report** 或 **Playtest feedback** 模板提交。
