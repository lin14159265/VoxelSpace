# VOXELSPACE · 体素星际

《我的世界》×《无人深空》风格的体素沙盒生存游戏：坠毁在太阳系的地球上，采集、建造、修复飞船，飞向太空、造访 8 大行星、停靠轨道空间站、购买大型殖民船，最终跃迁到比邻星系。纯浏览器运行（Three.js），全部素材与音效程序生成，零外部资源。

## 🎮 直接游玩（玩家 · 无需安装任何东西）

下载本仓库 ZIP（`Code → Download ZIP`）并解压，**双击根目录的 `VOXELSPACE.html`**，用 **Chrome / Edge** 打开即可开始游戏：

- 无需安装 Node.js、无需 `npm install`、无需启动服务器——单文件离线游玩。
- 存档与设置保存在浏览器本地，同一浏览器会自动续档；游戏内也可导出 / 导入存档文本（备份与换机）。
- 也可直接下载 Release 附件 `VOXELSPACE-standalone.zip`（只包含这一个游戏文件）。

## 从源码运行（开发者）

**需要 Node.js**（https://nodejs.org ，v18+）。首次运行前安装依赖：

```
npm install
```

然后双击 `start.bat`（或命令行 `npm start`），浏览器自动打开 **http://localhost:8080**。

> 若浏览器未自动打开，手动访问 http://localhost:8080 即可。
> 建议使用 Chrome / Edge（需支持指针锁定），独立显卡体验最佳。
> 单文件版由 `node tools/build-standalone.mjs` 重新生成。

## 玩法一览

你的飞船坠毁在地球上。新游戏会有一段俯瞰开场镜头（任意键跳过），随后按任务面板指引：

**坠毁求生 → 采集建造 → 修复飞船 → 起飞入太空 → 太阳系探索 → 空间站交易/升级 → 购大船 → 跃迁比邻星系（17 步任务链，通关后旅程完成面板，之后自由探索）。**

### 生存
- 四维状态：护盾 / 生命 / 生命维持（洞穴中消耗，**氧**自动补充）/ 危险防护（恶劣行星、夜晚、沙暴消耗，**钠**自动补充）。
- 采集钠花 / 氧草储备补给；洞穴内头灯自动点亮；夜间危险防护不足会受伤。
- 死亡后"紧急生命维持"在坠机点复活。

### 探索与发现
- **采矿与建造成长**：多功能工具 → **采矿光束 MkII**（R 键切换 **3×3 区域开采**，铜/金/玻璃升级）；挖掘高亮会随进度烧红收缩；手持建材时显示**绿/红预放置虚影**，新增**石砖**等真正建材。
- **基地占有感**：部署**基地终端**后记录重生点、夜晚可休息到清晨并回满状态（**240 秒冷却**）、终端 28m 内不刷怪；部署**储物箱**可把背包区物品一键存入/取出，基地与储物箱随世界和存档保留。
- **扫描（C）**：脉冲高亮周围资源点（青蓝）、飞船（琥珀）、**异常点（品红）**。
- **湖泊与浅水**：草地行星低洼处生成半透明湖泊；涉水减速，深水头没入会消耗生命维持，可在水格上填土建造。
- **异常点**：古代石碑遗迹（金矿/铜矿/信用点）、坠毁无人机（镀层/钠/氧）、应急补给箱（基础材料）——靠近按 E 调查，每颗行星约 27 处。
- **数据日志**：坠机点附近 3 个青色信标（发光立方+光柱），收集世界观文本。

### 战斗
- 夜间出没三种异星生物：夜行兽（均衡）、群居异虫（快脆、成队）、岩甲爬兽（慢厚重击）——行星类型决定构成。
- Q 键发射能量光束（3 发击杀夜行兽）；怪物**不穿墙**、隔墙打不到你，庇护所真正安全；白天怪物自燃。
- **战斗可读性**：怪物头顶实时血条（绿/橙/红）、攻击前摇红眼警示、命中硬直打断、闪避后怪物挥空进入短后摇；能量弹命中显示四向命中标记。
- **武器模块**：能量线圈（铜×3 + 碳×4 + 金×1，或空间站 450 信用点）——伤害 14→22、射速 +33%、弹丸变橙。

### 太空与空间站
- 修复飞船（脉冲引擎/座舱玻璃/发射燃料）后登船：W 油门、S 刹车、空格升、Shift/Ctrl 降、鼠标转向、V 切换座舱/追尾视角、E 降落离船。
- 爬升约 170 米进入太空：M 打开**三级星图**（恒星级 → 太阳系轨道图 → 行星系统图）选目标 → 罗盘显示目标名称/方向/距离 → 接近自动跃迁。
- **大气差异化**：飞船阻力与再入热障随真实大气密度变化——金星浓密大气强减速+2.6 秒等离子体热障，火星稀薄大气弱阻力+短促加热，月球等无大气天体真空滑翔、无热障。
- **月球可登陆**：星图进入地球系统 → 设定月球 → 飞近自动跃迁。月面重力仅地球 1/6、无大气黑天+白昼星空、月夜严寒、月尘与环形山；月轨上可飞回地球。
- **主要卫星共 12 颗可登陆**：月球、木星四大伽利略卫星（木卫一硫火山 / 木卫二冰下海洋 / 木卫三巨卫星 / 木卫四古老冰岩）、土卫六（浓密甲烷大气）、海卫一（逆行自转极寒）、天王星五卫星。
- **主小行星带可开采**：飞近按 E 开采铁氧体/碳/铜/金（有冷却与矿点数量），采空重新进入太空刷新；**微陨石撞击**让采矿有风险节奏。
- **太空战斗**：驾驶中 **Q 发射舰载能量弹**；小行星带附近会刷新**海盗拦截机**，击毁获得信用点赏金与“深空王牌”里程碑；舰船护盾/船体 HUD 实时显示，船体归零自动紧急返航。
- **行星任务板**：空间站任务板提供探索悬赏/送货/猎杀/采矿四类可重复悬赏；接单后 HUD 显示进度，游戏内行为自动推进，完成后 60 秒冷却，任务状态随存档保存。
- 地球轨道空间站（接近按 E 停靠）：交易（卖资源换信用点）、**可重复收购订单（45 秒冷却）**、**任务板（探索悬赏/送货/猎杀/采矿）**、飞船船坞（引擎/护盾升级 → **大型殖民船·曙光号**解锁跨星系，主线价已重平衡为 1400 信用点）、人员（3 名 NPC 对话埋剧情线）。
- 比邻星系跃迁门与**天狼星系跃迁门**：购大船后星图设定 → 飞近自动穿越（均可往返）；天狼星（A1V · 8.6 光年）拥有 2 颗推测行星。

### 成长反馈
- **里程碑（成就）23 项**：挖掘/合成/建造/击杀/探索/经济/飞船/星际/**卫星登陆/小行星开采**——达成即时弹"★"并**直接奖励信用点**（探索赚钱替代纯刷矿卖钱），暂停菜单可查看全部。
- 任务面板只显示当前与下一步（进度 `x/17`），不剧透后续内容。

## 已知说明

- 修改代码后刷新浏览器即可生效（无需重启服务器）。
- 游戏内"退出到主菜单"时进度自动保存；URL 中的 `seed` 参数即星球种子，可复制分享。
- 指针锁定由浏览器管理：切出页面会暂停游戏，点击画面或按任意键继续。
